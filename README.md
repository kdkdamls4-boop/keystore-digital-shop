# 🔑 KeyStore (DigitalKey Hub) — Интернет-магазин лицензионных цифровых ключей

Дипломный проект: Веб-ориентированная клиент-серверная информационная система для дистрибуции лицензионных цифровых ключей, программного обеспечения и подписок с мгновенной выдачей на экран и в защищенный личный кабинет.

---

## 🚀 Быстрый запуск

### Способ 1: Локальный запуск в один клик (Windows)
Просто дважды щелкните по файлу **`start.bat`** в корневой папке проекта.  
Скрипт автоматически проверит зависимости, запустит веб-сервер и откроет сайт в вашем браузере.

### Способ 2: Запуск в глобальный интернет через Cloudflare Tunnel (HTTPS)
Дважды щелкните по файлу **`start_tunnel.bat`**.  
Скрипт запустит сервер и создаст публичную HTTPS-ссылку (`https://xxxx.trycloudflare.com`), которую можно открыть со смартфона или отправить комиссии.

### Способ 3: Через командную строку / терминал
1. Убедитесь, что установлен [Node.js](https://nodejs.org/) (версия 22 или новее).
2. Откройте терминал в папке проекта и выполните:
```bash
npm install
npm start
```
3. Откройте в браузере:
- **Витрина магазина:** [http://localhost:3000](http://localhost:3000)
- **Учетные данные администратора:** логин `tpemeri`, пароль `rqllo` (вход через кнопку «Войти» в шапке сайта).
- **Демо-покупатель:** логин/email `alex.gamer@gmail.com`, пароль `gamer123`.

## 🛠️ Стек технологий
- **Фронтенд:** Vanilla HTML5, CSS3 (Apple Design System, светлая минималистичная палитра `#f8fafc` / `#ffffff`, акцентный `#0071e3`, шрифт Inter), ES6+ JavaScript, объемная 3D-графика преимуществ (Octane/Clay 3D).
- **Бэкенд:** Node.js, Express.js REST API, CORS.
- **База данных:** SQLite 3 с нативным синхронным драйвером `node:sqlite` (`DatabaseSync`), файл `keystore.db`.
- **Безопасность (RBAC):** Авторизация по Bearer-токенам сессий, хэширование паролей SHA-256, разграничение прав доступа (клиент / администратор), маскирование ключей в интерфейсе.

## 🌟 Ключевой функционал

### 1. Для покупателей (Клиентская часть)
- 🎮 **Каталог лицензий:** Игры для ПК и консолей (Steam, PlayStation, Xbox), программное обеспечение и ОС (Windows 11 Pro, Office 2024), подписки (Game Pass, PS Plus, Telegram Premium) и карты пополнения баланса.
- ⚡ **Объемные 3D-иконки:** Блок преимуществ с рендерами мгновенной доставки, 100% лицензии, безопасной оплаты и круглосуточной поддержки.
- 🔍 **Поиск и фильтры:** Живой поиск с задержкой debounce, фильтрация по платформам и категориям, сортировка по цене и популярности.
- 🛒 **Корзина и промокоды:** Оформление заказа с проверкой промокода (промокод `DIPLOM2026` со скидкой 15%).
- ⚡ **Мгновенная выдача ключей:** Ключи активации резервируются из пула лицензий и сразу отображаются на экране после оплаты.
- 🔐 **Защищенный личный кабинет:**
  - Вход исключительно по логину/email и паролю (гостевой доступ без пароля исключен).
  - История всех купленных ключей с изоляцией по пользователю.
  - Маскирование лицензионных ключей по умолчанию (`••••-••••-••••-••••`) с переключателем видимости (глазок) и кнопкой безопасного копирования.

### 2. Для администратора (Панель управления `tpemeri`)
- 🛡️ **Серверная защита (RBAC):** Все эндпоинты `/api/admin/*` защищены серверным middleware с проверкой роли `admin`.
- 📊 **Дашборд аналитики:** Выручка, количество заказов, проданные ключи и остаток ключей на складе.
- 📋 **Реестр заказов:** Просмотр оформленных заказов с выданными лицензионными ключами.
- ➕ **Добавление товаров:** Публикация новых цифровых товаров в каталог.
- 📥 **Склад лицензий:** Пакетная загрузка новых лицензионных ключей для автоматической выдачи.
- 📚 **База Знаний:** Управление статьями FAQ и служебными регламентами.
